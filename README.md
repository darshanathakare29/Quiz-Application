# Quiz-Application

A simple and interactive Quiz Application built using Java, designed to test users’ knowledge with multiple-choice questions. This project demonstrates Java fundamentals, OOP concepts, and CRUD operations while providing a real-world use case for learning and practice.

✨ Features

📝 Multiple Choice Questions (MCQs) – Each question has 4 options with one correct answer.

🎯 Score Calculation – Displays final score at the end of the quiz.

🔄 Dynamic Questions – Questions can be added, updated, or deleted from the database/file.

⏳ Timer Option (optional) – Set a time limit for answering.

📊 Result Display – Shows correct/incorrect answers and final performance.

🛠️ Tech Stack

**Programming Language:** Java (Core Java / Java Swing for GUI)

Database: MySQL (for storing questions & scores)

Concepts Used: OOP, Collections, JDBC (if using DB), Exception Handling

🚀 Use Cases

Mini project for students learning Java

College/university assignments

Practice application for Java concepts (loops, arrays, collections, OOP)
